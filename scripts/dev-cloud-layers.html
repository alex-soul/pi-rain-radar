Obscured sky / vertical visibility

DEV EXPERIMENT

OVC gives a cloud base. VV tells us how far upwards can be seen into an obscured sky. The haze is illustrative, with no measured top.

Use Layer 1's height control or “Height unavailable” to experiment; units, scale and font are in User controls. Marker-only is accepted. Optional DEV haze uses Cloud opacity; there is no separate haze-strength setting. Select Three layers below to recover.

01 / Cloud report

EDITABLE

Cloud groups only, e.g. FEW006 BKN014 OVC028. Also SKC, CLR, NSC, NCD, CAVOK or VV002. Empty means unavailable.

Height controls use the actual METAR hundreds-of-feet group. The plot converts to your chosen units.

User controls

SETTINGS COG

These controls are available in the widget settings. Cloud size changes width and height: smaller clouds form more banks, larger clouds form fewer. Coverage class and reported bases stay the same. Shape irregularity controls smooth versus uneven contours; its default is 100%.

Fixed scale stays at its chosen physical height when you switch units. Layers above it remain in the footer cloud groups; the range caption flags them.

DEV / Presentation experiments

Shape variation previews a different random arrangement; production will keep one stable seed per observation, assigned during acquisition.

DEV / Observation context

Original DDHHMMZ group in UTC, e.g. 131020Z. This is the observation time, not the time it was fetched.

Station, timestamp and LED state are simulated. This playground does not collect METARs or change the Pi.
