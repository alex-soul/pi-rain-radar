# Stats for nerds

Stats for nerds shows the installation's current acquisition and calculation state. It stays live during Archive playback and does not follow the selected frame.

Enable it in Screen settings → Side buttons. Main and Overview show the active provider, current acquisition state, latest observation age and check timing. Clouds, OpenWeather and Camera show current collection status and freshness. A lost or stale backend connection is marked explicitly.

Aviation shows the station, separate METAR/TAF usability and last successful checks. Grass shows readiness, its decimal estimate, calculation time and a useful blocking reason. A ready Grass calculation is still uncalibrated; an eligible zero is a valid result.

Historical window counts, gap/late-arrival histories, camera timestamp counts and monthly usage totals are excluded from this panel. Archive availability remains in the playback/Archive UI; provider usage controls remain with their settings.
